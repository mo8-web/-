# مشروع نبض اليمن

مشروع موقع إخباري باستخدام:

- Python
- Flask
- SQLite
- Requests
- BeautifulSoup
- HTML5
- CSS3
- JavaScript

مصدر الأخبار الافتراضي:
https://www.alhadath.net/

## 1. إنشاء البيئة الافتراضية

افتح Terminal داخل مجلد المشروع:

```bash
python -m venv venv
```

ثم فعّل البيئة على Windows:

```bash
venv\Scripts\activate
```

## 2. تثبيت المكتبات

```bash
pip install -r requirements.txt
```

## 3. تشغيل الموقع

```bash
python app.py
```

بعدها افتح:

http://127.0.0.1:5000

## 4. تحديث الأخبار يدوياً

افتح:

http://127.0.0.1:5000/refresh

## 5. ماذا يفعل المشروع؟

عند تشغيل app.py:

1. ينشئ قاعدة البيانات news.db.
2. يبحث في الصفحة الرئيسية والأرشيف عن روابط الأخبار.
3. يفتح صفحات الأخبار.
4. يحاول استخراج العنوان والصورة والتاريخ ونص الخبر.
5. يحفظ البيانات في SQLite.
6. يمنع تكرار الخبر باستخدام source_url.
7. يعرض الأخبار في واجهة عربية متجاوبة.
8. يشغل تحديثاً تلقائياً كل 10 دقائق أثناء تشغيل البرنامج.

## ملاحظة مهمة عن الصور والمحتوى

المشروع يعرض رابط الصورة الأصلي من المصدر بدلاً من إعادة رفع الصورة على سيرفرك، مع إظهار رابط المصدر الأصلي.

قبل نشر الموقع للعامة أو استخدام المحتوى والصور تجارياً، تأكد من شروط الاستخدام وحقوق إعادة النشر الخاصة بالمصدر.

## ملاحظة تقنية

مواقع الأخبار قد تغيّر بنية HTML الخاصة بها. لذلك يحتوي scraper.py على أكثر من طريقة احتياطية لاستخراج البيانات، لكن قد تحتاج بعض المحددات إلى تعديل إذا غيّر الموقع تصميمه.
